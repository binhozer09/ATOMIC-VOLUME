ATÔMIC VOLUME
=============
Android volume booster prototype in Kotlin.

Includes buttons for 120%, 150%, 175%, 190%, MAX 200%, and normal 100%.

Uses Android LoudnessEnhancer on global audio session 0. Global effects are device/OEM dependent and may be rejected or ignored. Percentages are gain targets, not guaranteed acoustic loudness. High volume can damage hearing.

Build by opening the repository in Android Studio, syncing Gradle, and building the app debug variant.
